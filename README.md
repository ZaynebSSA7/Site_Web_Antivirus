# Projet Antivirus
Ce projet est un mini-site statique sur le thème des antivirus, développé collaborativement.

## Commandes Git principales utilisées
- `git clone <url>` : Cloner un dépôt distant.
- `git checkout -b <nom-branche>` : Créer et se positionner sur une nouvelle branche.
- `git add .` : Ajouter tous les fichiers modifiés au prochain commit.
- `git commit -m "message"` : Créer un commit avec un message descriptif.
- `git push origin <nom-branche>` : Pousser la branche locale sur le dépôt distant.
- `git pull origin <nom-branche>` : Récupérer les modifications d’une branche distante.
